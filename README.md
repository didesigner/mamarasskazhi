# «Мама, расскажи» — AR-сайт v2

Это ЧИСТАЯ новая версия сайта. Старые файлы можно удалить и заменить этими.

Система рассчитана на:
- много книг;
- много оживающих страниц внутри каждой книги;
- отдельный QR на каждую книгу;
- одно видео на одну распознаваемую страницу.

---

## 1. Что куда загружать

Для книги про динозавров уже создана папка:

books/dino/

В ней:

books/dino/targets-source/
    Здесь храни обычные JPG/PNG страниц, из которых создаётся файл распознавания.

books/dino/videos/
    Здесь лежат оживающие видео.

books/dino/targets.mind
    ЭТОТ ФАЙЛ НУЖНО БУДЕТ СОЗДАТЬ ИЗ КАРТИНОК СТРАНИЦ.
    Обычного JPG недостаточно: MindAR сначала компилирует картинки в .mind.

---

## 2. Первая страница с динозаврами

Картинку сохрани так:

books/dino/targets-source/dino-01.jpg

Видео сохрани так:

books/dino/videos/dino-01.mp4

В books.js уже прописано, что:

targetIndex 0 -> books/dino/videos/dino-01.mp4

То есть код для первой страницы уже готов.

Но AR начнёт узнавать страницу только после появления:

books/dino/targets.mind

---

## 3. Что такое targets.mind

Это не картинка и не видео.

Это специальный файл распознавания MindAR.
Он создаётся из одной или нескольких картинок страниц.

Например, если при создании targets.mind картинки загрузить в таком порядке:

0 = dino-01.jpg
1 = dino-02.jpg
2 = dino-03.jpg

то в books.js:

targetIndex: 0 = первая картинка
targetIndex: 1 = вторая
targetIndex: 2 = третья

Порядок очень важен.

---

## 4. Как добавить вторую страницу

1. Положи:

books/dino/targets-source/dino-02.jpg

2. Положи:

books/dino/videos/dino-02.mp4

3. Пересоздай targets.mind уже из ДВУХ картинок:
   dino-01.jpg
   dino-02.jpg

4. В books.js добавь второй объект:

{
  targetIndex: 1,
  name: "Динозавры — страница 2",
  video: "./books/dino/videos/dino-02.mp4",
  width: 1,
  height: 0.707,
  transparent: false
}

---

## 5. Как добавить новую книгу

Допустим, книга называется ocean.

Создай:

books/ocean/
books/ocean/targets-source/
books/ocean/videos/

И файл:

books/ocean/targets.mind

Потом в books.js добавь новую книгу с id "ocean".

QR для неё будет вести на:

https://ТВОЙ-АДРЕС/?book=ocean

Для динозавров:

https://ТВОЙ-АДРЕС/?book=dino

Например у тебя сейчас:

https://didesigner.github.io/mamarasskazhi/?book=dino

---

## 6. QR и значок ✦ — это НЕ одно и то же

QR:
- просто открывает нужную книгу на сайте;
- его можно поставить один раз в начале книги.

Значок ✦:
- можно поставить на страницах, которые умеют оживать;
- это просто подсказка ребёнку/родителю;
- камера НЕ обязана распознавать сам значок.

Камера распознаёт саму иллюстрацию страницы через targets.mind.

---

## 7. Если персонаж ребёнка меняется

Самая надёжная схема:
- стараться, чтобы большая часть фона и других героев оставалась одинаковой;
- при создании target-картинки использовать вариант с постоянной композицией;
- анимацию делать так, чтобы персонализированный ребёнок не перекрывался.

Если видео MP4 — оно непрозрачное.
Если нужен прозрачный ребёнок/прозрачные участки, лучше использовать WebM с alpha и в books.js поставить:

transparent: true

А путь заменить на .webm.

---

## 8. Как заменить сайт на GitHub

1. Открой репозиторий didesigner/mamarasskazhi.
2. Удали старые index.html, styles.css, app.js и старые тестовые файлы.
3. Загрузи ВСЁ содержимое этой новой папки в корень репозитория.
4. Сохрани структуру папок.
5. GitHub Pages сам обновит сайт.

Главный файл, который ты потом чаще всего будешь менять:
books.js

---

## 9. ВАЖНО

Эта версия использует библиотеки A-Frame + MindAR через CDN.
Телефону нужен интернет при первом открытии страницы.

Для работы камеры нужен HTTPS — GitHub Pages его уже даёт.
